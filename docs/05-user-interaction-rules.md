# Правила взаимодействия с пользователем

## Основной принцип

Пользователь должен понимать:

- что сейчас будет сделано;
- зачем;
- что требуется от него;
- какие есть варианты;
- какой вариант рекомендуется;
- какие риски;
- что проверить после действия.

## Вопросы

Если есть реальный выбор, показывать его меню.

Пример:

```text
Как настроить базу 3x-ui?

1. PostgreSQL (рекомендуется)
2. SQLite compatibility mode
3. Использовать существующую БД
```

Если параметр можно определить автоматически — не спрашивать без причины.

## Секреты

Пример:

```text
Пароль PostgreSQL:

1. Сгенерировать безопасный пароль
2. Ввести самостоятельно
```

Ввод пароля — скрытый.

## Команды для пользователя

Если требуется ручное действие, инструкция должна иметь форму:

### Где выполнить

Например:

> Выполните на новом VPS по SSH от пользователя с sudo.

### Команды

```bash
sudo apt-get update
sudo apt-get install -y curl ca-certificates
```

### Проверка

```bash
curl --version
```

### Ожидаемый результат

Например:

> Команда должна вывести версию curl и завершиться без ошибки.

### Важные примечания

Например:

> Эта команда безопасна для текущего SSH-соединения и не меняет firewall.

Или:

> Следующий шаг меняет SSH port. Не закрывайте текущую SSH-сессию до проверки второго подключения.

## Запрещённый стиль инструкций

Нельзя:

> Настройте DNS.

Нужно:

- назвать запись;
- назвать тип;
- показать значение;
- объяснить TTL, если важно;
- сказать, как проверить через `dig`.

Нельзя:

> Проверьте firewall.

Нужно:

```bash
sudo ufw status numbered
sudo ss -lntup
```

и объяснить, что именно искать.

## Ошибки

Сообщение об ошибке должно содержать:

- этап;
- фактическую ошибку;
- краткую вероятную причину;
- диагностические команды;
- что пользователь должен сделать;
- как продолжить (`resume`), если поддерживается.

Пример:

```text
[ERROR] TLS certificate was not issued.

Причина:
домен example.com сейчас резолвится в 203.0.113.20,
а public IPv4 этого VPS — 198.51.100.40.

Исправьте A record у DNS-провайдера.

Проверка:
dig +short A example.com

После исправления:
sudo vps-bootstrap resume
```

## Important notes

"Важные примечания" обязательны перед:

- SSH changes;
- firewall changes;
- reboot;
- DNS changes;
- destructive operations;
- DB migration;
- changing port 443 owner;
- enabling WARP/routing changes;
- deleting old configs;
- changing TLS setup.
